# static-library

Self-updating catalog of every `kody-w/static-*` resource — deterministic, zero-dependency
integration simulators served as static JSON on GitHub Pages.

**Browse: https://kody-w.github.io/static-library/**

The page enumerates the GitHub API on every load and probes each repo's Pages site for
`api/v1/index.json` and `mcp/manifest.json`, so new static-* repos appear automatically.
